# EarnX Demo / Prank Earning App

A clearly labeled Flutter prototype for Android and iPhone.

## Safety / scope
- Demo coins only.
- No real-money earning.
- No real withdrawal.
- Withdrawal action explicitly explains that payouts are disabled.
- Do not present fictional balances as real earnings.

## Run
1. Install Flutter.
2. `flutter pub get`
3. `flutter run`

Android build:
`flutter build apk`

iOS build (requires macOS + Xcode):
`flutter build ios`

This prototype uses no external packages beyond Flutter/Cupertino icons.
